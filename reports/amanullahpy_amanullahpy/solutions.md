## Installation & Setup

To get this project up and running on your local machine, follow these steps. This project typically consists of a Next.js frontend and a NestJS backend, interacting with a PostgreSQL database.

### Prerequisites

Ensure you have the following software installed:

*   **Git**: For cloning the repository.
    *   [Download Git](https://git-scm.com/downloads)
*   **Node.js & npm/Yarn**: For running JavaScript/TypeScript applications (frontend and backend).
    *   [Download Node.js](https://nodejs.org/en/download/) (includes npm)
    *   [Install Yarn](https://classic.yarnpkg.com/lang/en/docs/install/) (optional, but recommended if `yarn.lock` is present)
*   **PostgreSQL**: The relational database used by the backend.
    *   [Download PostgreSQL](https://www.postgresql.org/download/)

### 1. Clone the Repository

Start by cloning the project repository to your local machine:

```bash
git clone https://github.com/amanullahpy/amanullahpy.git
cd amanullahpy
```

### 2. Backend Setup (NestJS)

Navigate into the backend directory, install dependencies, configure environment variables, and start the server.

```bash
cd backend # Adjust path if your backend is in a different directory, e.g., 'api' or 'server'
npm install # or yarn install
```

#### Environment Variables

Create a `.env` file in the `backend/` directory by copying the example file. This file will hold your database connection string and other sensitive configurations.

```bash
cp .env.example .env
```

Open the newly created `.env` file and update the following variables:

```ini
# Example .env content
PORT=3000
DATABASE_URL="postgresql://user:password@localhost:5432/mydatabase"
# Add any other required environment variables for authentication, external services, etc.
```

*   Replace `user`, `password`, and `mydatabase` with your PostgreSQL credentials and desired database name.
*   Ensure your PostgreSQL server is running and accessible.

#### Database Migrations

Run database migrations to set up the schema:

```bash
npm run typeorm:migrate # Or the equivalent command for your ORM (e.g., 'npm run prisma:migrate')
```

#### Start the Backend Server

Once configured, start the NestJS development server:

```bash
npm run start:dev
```

The backend API should now be running, typically accessible at `http://localhost:3000`.

### 3. Frontend Setup (Next.js)

Open a new terminal window, navigate into the frontend directory, install dependencies, configure environment variables, and start the development server.

```bash
cd ../frontend # Adjust path if your frontend is in a different directory, e.g., 'client' or 'web'
npm install # or yarn install
```

#### Environment Variables

Create a `.env.local` file in the `frontend/` directory by copying the example file. This file will hold environment variables specific to the frontend, such as the backend API URL.

```bash
cp .env.local.example .env.local
```

Open the `.env.local` file and update the following variables:

```ini
# Example .env.local content
NEXT_PUBLIC_API_URL="http://localhost:3000"
# Add any other required public environment variables
```

*   Ensure `NEXT_PUBLIC_API_URL` points to the address where your backend server is running.

#### Start the Frontend Development Server

Start the Next.js development server:

```bash
npm run dev
```

The frontend application should now be running, typically accessible at `http://localhost:3001` (or another port if configured).

### 4. Access the Application

*   **Frontend**: Open your web browser and navigate to `http://localhost:3001` (or the port indicated by the `npm run dev` command).
*   **Backend API**: The API endpoints are available at `http://localhost:3000`. You can test these using tools like Postman or by interacting with the frontend.

```
