## Installation & Quickstart

This guide will help you set up and run the portfolio project locally for development or to build it for production.

### Prerequisites

Ensure you have the following installed on your system:

*   **Node.js**: Version 18.x or higher (LTS recommended).
*   **npm** (Node Package Manager): Comes bundled with Node.js. Alternatively, you can use `yarn` or `pnpm`.
*   **Git**: For cloning the repository.

### Clone the Repository

First, clone the repository to your local machine using Git:

```bash
git clone https://github.com/amanullah/amanullah_portfolio.git # Replace with actual repo URL
cd amanullah_portfolio
```

### Install Dependencies

Navigate into the project directory and install the required dependencies using npm:

```bash
npm install
# Or if you prefer yarn:
# yarn install
# Or if you prefer pnpm:
# pnpm install
```

### Environment Variables

This project may utilize environment variables for sensitive information or configuration. Create a `.env.local` file in the root of the project directory.

```bash
touch .env.local
```

Populate `.env.local` with necessary variables. For example:

```
# Example environment variables (adjust as per actual project needs)
NEXT_PUBLIC_API_URL=https://api.example.com
# Add any other API keys or configuration variables here
```

**Note:** The `.env.local` file is ignored by Git and should not be committed to the repository.

### Running Locally

#### Development Mode

To start the development server, which includes hot-reloading and error reporting, run:

```bash
npm run dev
```

The application will typically be accessible at `http://localhost:3000`.

#### Production Mode

To build the application for production and then serve it:

1.  **Build the project:** This compiles the Next.js application for optimal performance.

    ```bash
    npm run build
    ```

2.  **Start the production server:**

    ```bash
    npm run start
    ```

    The production application will typically be accessible at `http://localhost:3000`.

### Deployment (Optional)

This project is built with Next.js, making it highly suitable for deployment on platforms like Vercel (as indicated by the existing portfolio URL).

To deploy to Vercel:

1.  Install the Vercel CLI: `npm i -g vercel`
2.  Log in to Vercel: `vercel login`
3.  From the project root, run: `vercel`
    *   Follow the prompts to link your project and deploy.

For other hosting providers, refer to their specific documentation for deploying Next.js applications.

## Installation & Setup

To get a local copy of this project up and running, follow these steps.

### Prerequisites

Ensure you have the following installed on your system:

*   Node.js (LTS version recommended)
*   npm or Yarn package manager

### 1. Clone the Repository

First, clone the `amanullah_portfolio` repository to your local machine using Git:

```bash
git clone https://github.com/your-username/amanullah_portfolio.git
cd amanullah_portfolio
```

### 2. Install Dependencies

Navigate into the project directory and install the required dependencies using your preferred package manager:

```bash
# Using npm
npm install

# Or using Yarn
# yarn install
```

### 3. Environment Variables

This project may utilize environment variables for certain configurations (e.g., API keys, analytics IDs). Create a `.env.local` file in the root of the project directory:

```bash
touch .env.local
```

Populate `.env.local` with any necessary variables. A common example for a Next.js project might include:

```env
# Example environment variables (adjust as per actual project needs)
NEXT_PUBLIC_GA_ID=UA-XXXXXXXXX-Y # Google Analytics ID (if used)
# Add any other API keys or configuration variables here
```

**Note:** Do not commit your `.env.local` file to version control. It is typically ignored by default via `.gitignore`.

### 4. Run the Development Server

Once dependencies are installed and environment variables are set, you can start the development server:

```bash
# Using npm
npm run dev

# Or using Yarn
# yarn dev
```

The application will typically be accessible at `http://localhost:3000` in your web browser.

### 5. Build for Production

To create an optimized production build of the application, use the following command:

```bash
# Using npm
npm run build

# Or using Yarn
# yarn build
```

This command compiles the TypeScript code and Next.js assets into the `.next` directory, ready for deployment.

### 6. Start Production Server (Optional)

After building, you can locally serve the production build to test it:

```bash
# Using npm
npm run start

# Or using Yarn
# yarn start
```

This will run the optimized production version of the portfolio, typically on `http://localhost:3000`.
